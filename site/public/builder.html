Get your files

Step-by-step beginner's guide

  1. Install the skill: paste github.com/Siddharthmehdiratta/founder-skill-plus into Claude and say "install skill".
  2. Put both files in a founder folder in your project.
  3. In Claude, type /founder-consumer and say "use my founder/customer.json and founder/pitch.md". Start with 20 buyers for a cheap first look.
  4. Open results.html for the full interactive report.
