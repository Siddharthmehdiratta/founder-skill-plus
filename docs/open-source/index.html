What's inside

  • site/

    This website, built with Next.js and Tailwind from the free Velora UI template.

  • site/public/

    The panel builder, guide, review analysis and sample reports, in plain HTML and JavaScript.

  • docs/

    The published website that GitHub Pages serves.

  • skills/

    Claude Code skills: the AI customer panel, the score, the reports and the other founder skills.

  • tests/

    Automatic checks for the maths and every page.

Use it in Claude Code

  1. 1

    Open Claude Code. In the terminal, the desktop app or the web.

  2. 2

    Paste the link to this repo and say "install this skill pack".

  3. 3

    Ask for a panel. For example: "test my study app on 30 customers in India".

git clone https://github.com/Siddharthmehdiratta/founder-skill-plus.git
cd founder-skill-plus/docs
python3 -m http.server 8000
